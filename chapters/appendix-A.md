## 附录 A　技术选型决策树

按"现象 → 对策"的方式快速定位。

```
你的 RAG 目前的主要问题是什么？
│
├─ 0. 还没有评估集？
│     └─→ 先做第 20 章：建 50~100 条评估样本 + 检索指标 + 忠实度
│
├─ 1. 【找不到】答案在库里，但没被检索到（Recall 低）
│     ├─ 专有名词/编号/代码搜不到 ──────────→ 混合检索（3）
│     ├─ 块脱离文档后不知所云 ───────────────→ 上下文检索（12）
│     ├─ 块切断了语义 ───────────────────────→ 语义/结构分块（2）
│     ├─ 用户措辞与文档差异大 ───────────────→ 多查询（6）、HyDE（7）、改写（5）
│     ├─ 多轮对话指代不明 ───────────────────→ 查询改写（5）
│     └─ 版本/时间/部门混淆 ─────────────────→ 元数据过滤（11）
│
├─ 2. 【排不准】答案在候选里，但没进入 Top-k（Precision/排序差）
│     ├─ 通用解法 ───────────────────────────→ 重排序（4）
│     └─ 噪声多、上下文太长 ─────────────────→ 压缩（13）、减小 k
│
├─ 3. 【答不全】检索命中但缺前提/上下文
│     └─────────────────────────────────────→ 父子分块（10）
│
├─ 4. 【复杂问题】
│     ├─ 多部分/多跳 ────────────────────────→ 查询分解（8）
│     ├─ 多数据源（文档/SQL/Web） ───────────→ 查询路由（9）
│     ├─ 全局总结/关系型问题 ────────────────→ GraphRAG（14）
│     └─ 开放式研究、需要试错 ───────────────→ Agentic RAG（15）
│
├─ 5. 【会胡编】
│     ├─ 检索到无关资料仍硬答 ───────────────→ Corrective RAG（16）
│     ├─ 答案没有依据 ───────────────────────→ Self-RAG 式自检（17）
│     └─ 库里本来就没有 ─────────────────────→ 拒答 + Web 回退（16）
│
├─ 6. 【太慢太贵】
│     └─────────────────────────────────────→ 自适应（18）、压缩（13）、小模型、缓存
│
└─ 7. 【文档不只文字】
      └─────────────────────────────────────→ 多模态 RAG（19）
```
